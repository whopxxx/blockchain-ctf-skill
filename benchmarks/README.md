# Public Benchmark Corpus

This directory tracks external evaluation candidates. It does not vendor challenge code or solutions.

Before enabling a candidate, verify its official upstream source, immutable commit or release, challenge path, license/redistribution constraints, setup command, player-visible input, and native success oracle. Fetch it into an isolated cache and keep solution material outside the solving agent's context.

The initial priority candidates come from the curated catalog in `reference.txt`. Their metadata remains `candidate-unverified` until the execution agent checks the upstream repositories.
