`拿到题目仓库`

→ `本地验证`
→ `输出 exploit + 原理`

针对不同技术栈再分支：

`Solidity/EVM`
→ Foundry + Slither + Echidna/Medusa + cast/anvil

`Sui Move`
→ Move object ownership + PTB + shared object + capability 分析

`Solana`
→ account ownership + PDA + signer + CPI + Rust memory/account validation

`跨链`
→ source chain → relayer → attestation → destination chain，重点检查 message authenticity 和 accounting

`链上取证`
→ transaction trace + event + bytecode + fund flow。

其中我最建议你先看 **solexploit-gen**。它已经非常接近“AI 自动做 CTF”的架构了：

```text
Target.sol
    ↓
LLM Agent
    ↓
阅读目标合约
    ↓
生成 Exploit.sol
    ↓
Anvil 部署
    ↓
执行 pwn()
    ↓
检查 invariant 是否被破坏
    ↓
失败 → 看错误 → 修改 exploit → 再跑
```

而且它不是让另一个 LLM 判断“攻击成功没成功”，而是真的用 **Anvil 执行 EVM bytecode**。它目前内置了 `reentrancy / access control / price oracle / signature replay` 等漏洞类型。这个设计非常适合拿来改成 CTF Solver。

[GPT-Exploit-Generator](https://github.com/Crimson798/GPT-Exploit-Generator) 更像你实际刷比赛时想要的东西。它会：

```text
输入 vulnerable contract
       ↓
GPT 分析
       ↓
生成 Attack.sol
       ↓
生成 Foundry test
       ↓
forge build
       ↓
编译错误？
 ├─ Yes → 把错误喂回 GPT → 修复
 └─ No
       ↓
forge test -vvv
       ↓
exploit 失败？
 ├─ Yes → 分析 EVM trace → 改 exploit
 └─ No → PoC 完成
```

这个“**生成 → 编译 → trace → 修复 → 再验证**”循环，其实就是一个很不错的 CTF Agent 雏形。

如果你说的是严格意义上的 **Skill**，那 [solidity-agent-kit](https://github.com/0xlayerghost/solidity-agent-kit) 最值得看。它已经按照 agent skill 的方式组织，而且 README 明确支持 **Codex CLI、Claude Code、Cursor、Windsurf**。里面已经有 `solidity-security`、`solidity-audit`、`solidity-debug`、`solidity-testing`、`defi-security` 等 skill。

但它偏“开发 + 审计”，还缺 CTF 最重要的一层：

```text
识别 win condition
→ 反推 invariant
→ 找攻击路径
→ 编写攻击合约
→ forge test 验证
```

所以如果是你的用途，我不会从零写。

我会直接采用：

**`solidity-agent-kit` 的 Skill 结构**
+
**`synapse_agents` 的多 Agent 漏洞分析**
+
**`solexploit-gen` 的真实执行 verifier**
+
**`GPT-Exploit-Generator` 的自动修复循环**
+
**Foundry / Slither / Echidna / Manticore**

最后形成：

```text
              Blockchain CTF Agent

                     │
              Challenge Parser
                     │
        ┌────────────┼─────────────┐
        ↓            ↓             ↓
    Solidity       Move         Solana
      Agent        Agent          Agent
        │
        ↓
  Contract Mapper
        │
        ↓
 Invariant Analyzer
        │
        ↓
 Vulnerability Hunter
        │
  ┌─────┼──────┬──────────┐
  ↓     ↓      ↓          ↓
Slither LLM  Fuzzer   Symbolic Exec
  │

        ↓
 Exploit Planner

 Exploit.sol

     FAILED
        │
     trace
        │

                  │
                  ↓
```

目前最大的空白反而很明显：**这些 GitHub 项目基本都严重偏 EVM/Solidity。**

我们前面看的 2026 CTF 已经开始大量出现：

`Sui Move / TON / Stellar / cross-chain / PTB / shared object / relayer / transient storage`

所以如果做一个 **真正面向现代 Blockchain CTF 的 Agent**，其实还有挺大的空间。

尤其可以直接拿我们前面整理的 **30 道真实 CTF 题作为 benchmark**，测试 Agent 能不能从 `PP Farming → Outer Stellar → Lootboxes → Transient Heist → Solalloc` 逐级解题。这个项目会比单纯再做一个 Solidity audit agent 有意思得多。
